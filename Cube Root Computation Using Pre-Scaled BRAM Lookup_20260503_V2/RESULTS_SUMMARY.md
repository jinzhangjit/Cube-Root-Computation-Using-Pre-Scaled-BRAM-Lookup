# Reproduced Results Summary (Chip-Level / Non-OOC)

Paper: *An Ultra-Low Resource FPGA Architecture for Cube Root Computation Using Pre-Scaled BRAM Lookup*

## Tool and Target

- FPGA: Xilinx Kintex-7 `xc7k420tffg1156-2L`
- Vivado: 2018.3, 64-bit
- Synthesis mode: **standard project flow (non-OOC)** — top-level I/O buffers
  (IBUF/OBUF) auto-inferred and included in timing/power
- MATLAB: R2025b, theoretical precision mode
- Input format: Q2.22, valid domain `y in [0.5, 4)`
- Output format: Q1.23
- Clock period constraint: 10.0 ns (100 MHz target)

## Vivado Post-Route Timing

Source report: `results/synthesis/timing_post_route.rpt`

| Metric | Result |
| :-- | --: |
| Clock period constraint | 10.000 ns |
| Setup WNS | **-1.371 ns** (failing) |
| Hold WHS | -0.220 ns |
| Effective minimum period | 11.371 ns |
| **Effective F_max** | **87.94 MHz** (paper: 87.9 MHz) |
| Throughput (1 cycle/op) | 87.94 MOPS |
| Pipeline latency | 3 cycles |

The setup WNS failure at 10 ns is **expected at chip level**: the critical path
runs `result_reg[*]/C → OBUF → output port`, where the OBUF contributes
~3.8 ns and the 2.0 ns output-delay budget consumes another 2.0 ns; the total
exceeds the 10 ns clock period by 1.371 ns. The implied closing period of
11.371 ns yields F_max = 87.94 MHz.
